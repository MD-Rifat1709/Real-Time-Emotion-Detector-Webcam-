# 🎭 Real-Time Emotion Detector

Detects emotions from webcam images using deep learning.
This project is a real-time emotion detection system built with Streamlit, OpenCV, and TensorFlow. It captures webcam images, detects faces, and predicts emotions using a Convolutional Neural Network (CNN) model trained on the FER-2013 dataset.

🚀 Features
Real-time face and emotion detection via webcam

Option to use a pretrained model or train your own

Interactive web app built with Streamlit

Fully deployable on Streamlit Cloud

Lightweight and easy to run locally or in the cloud

🧠 Emotions Detected
Angry, Disgust, Fear, Happy, Sad, Surprise, Neutral
## 🧠 Options
- Use Pretrained Model (FER-2013)
- Train Custom Model from FER-2013 CSV
